03Proximity-based outliers, and where they go wrong

The extension, taken from Breiman and Cutler's later documentation rather than the 2001 paper, scores how rarely each row shares a leaf with others of its class. The proximity matrix is structurally right: within-class proximity is 0.681 against 0.008 across classes.

The outlier score does not hold up as cleanly. The benign class is so tight that its median absolute deviation is 78 times smaller than the malignant one, so a threshold of 3 flags 28% of all rows. One suspected cause is that proximities counted in-bag rows, which fully grown trees memorise. The ablation below recomputes them with out-of-bag pairs only, the definition in Hastie, Tibshirani & Friedman (§15.3.3).

The hypothesis is only half right. In-bag counting explains about half of the MAD gap, but the flag rate barely moves, so the per-class normalisation is still the main problem. The report recommends a per-class top-5% cutoff instead of a fixed threshold.
